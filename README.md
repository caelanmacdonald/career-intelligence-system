\# Career Intelligence Dashboard



A Business Intelligence platform for managing job applications, employer research and career analytics.



\## Technologies



\- PostgreSQL (Neon)

\- Python

\- Power BI

\- Git \& GitHub



\## Project Goals



\- Build a database of UK employers.

\- Track job opportunities and applications.

\- Analyse application success using Power BI.

\- Automate vacancy monitoring.

\- Demonstrate production-style BI workflows.
